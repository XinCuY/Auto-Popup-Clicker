# 窗口及后台静默自动化交互工具 (Auto-Clicker)

## 项目简介
本项目是一个基于 Python 和 Windows 底层 API 实现的自动化交互工具，主要用于解决特定桌面软件中繁杂的弹窗确认问题。项目摒弃了传统的前台模拟鼠标方案，采用底层窗口消息机制，保证了用户在运行自动化工具时，不影响正常使用电脑（如看视频、打字）。

*(注：本项目为个人学习实践，部分底层 API 的实现思路参考了开源社区的优秀代码，并在此基础上进行了业务逻辑的调整与适配。)*

## 核心功能与实现
1. 高效窗口捕获 (WGC)：
   放弃传统的全屏截图/录屏，采用 Windows Graphics Capture (WGC) API，实现对目标窗口画面的高效、低延迟截取。降低了 CPU 占用率，并为后续的图像识别提供了更精准的数据源。
2. 后台静默交互 (PostMessage)：
   采用 PostMessage 消息机制向目标窗口（HWND）发送点击/按键指令。实现后台无干扰点击，不抢占物理鼠标焦点。
3. 状态轮询与检测：
   结合基础图像识别技术，定时轮询窗口画面，当检测到特定特征（如弹窗出现）时，自动触发底层交互指令。

## 技术栈
* 编程语言：Python
* 核心技术：Win32 API (WGC 捕获、PostMessage 消息机制)
* 其他：基础图像识别、自动化控制

## 学习与反思
* 技术借鉴与移植：通过阅读开源社区的代肝脚本源码，学习到了 WGC 和 PostMessage 的高级用法，并成功将其剥离、重构应用到本项目中。
* 跨设备兼容性：在将代码打包分发到目标设备（不同电脑）运行时，遭遇了环境依赖缺失及兼容性问题导致运行失败。目前未彻底解决，但深刻认识到了软件部署环节的复杂性，并积累了初步的排查经验。
